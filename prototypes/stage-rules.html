Hiring Stage Rules: Prototype

Throwaway demo for the Applicant Tracking System planning interview. Nothing here is saved.

The question this answers

Which moves between hiring stages should staff be allowed to make, and how should those rules interact with archiving or deleting a candidate?

Pick a rule set below, then press buttons or run the guided scenarios. Watch for moments where you think "that shouldn't be possible" or "that should be allowed." Those moments are the decisions we need to make. You can switch rules at any time without losing the current state.
